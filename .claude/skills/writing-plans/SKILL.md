# writing-plans

`~/.claude/skills/base-writing-plans/SKILL.md` and follow it as written.

This file exists only so the bare name `writing-plans` resolves here: shared skills are
prefixed `base-` because Claude Code always prefers a personal skill over a
project one of the same name, and that order cannot be configured.
